# Dot_it · Pixel Character Playground

**DEV-001 — 로컬 캐릭터 스프라이트 실험실**

GitHub Pages에서 작동하는 HTML/CSS/JavaScript + Phaser 3 기반 도트 캐릭터 체험 웹입니다. 현재는 **한 사람만 조작하는 로컬 프로토타입**이며, 로그인/영구 저장/멀티플레이는 다음 개발 단계에서 추가합니다.

## DEV-001 구현 기능

- 데모 펭귄 캐릭터를 처음부터 바로 이동할 수 있습니다.
- PNG 시트 파일을 선택하거나 드래그앤드롭으로 불러옵니다.
- 프레임 가로·세로 크기(8~256px), IDLE/WALK 시작 번호·프레임 수·FPS를 설정합니다.
- 스프라이트 시트 격자에서 칸을 클릭해 해당 애니메이션의 시작 번호를 지정합니다.
- 큰 시트에서도 미리보기는 **첫 번째 행부터** 표시되며 가로·세로 스크롤로 전체 프레임을 볼 수 있습니다.
- 업로드한 이미지에서 후보 프레임 크기를 추정해 보여줍니다(예: 384×240 PNG → **48×48**, 8열×5행). 추정값이므로 실제 시트 구조가 다르면 직접 수정하세요.
- 선택한 IDLE/WALK 프레임을 별도 미리보기에서 반복 재생합니다.
- **프레임별 재생 시간 사용**을 켜면 IDLE/WALK 각 프레임을 **20~3000ms** 범위에서 개별 설정할 수 있습니다.
- 각 프레임의 도트 썸네일과 번호가 표시되며, 시간 변경이 **애니메이션 미리보기**에 바로 반영됩니다.
- **캐릭터에 설정 적용하기**를 누르면 실제 광장의 애니메이션에도 개별 프레임 시간이 반영됩니다.
- IDLE과 WALK 시간 설정은 독립적이며, 끄면 기존 전체 FPS 모드로 돌아옵니다.
- **전체 FPS 기준으로 초기화**로 개별 재생 시간을 현재 FPS에 맞춰 다시 설정할 수 있습니다.
- **캐릭터에 설정 적용하기**를 클릭하면 광장에 변경 사항이 반영됩니다.
- **WASD 또는 방향키**로 8방향 이동하며 이동할 때 WALK, 멈췄을 때 IDLE을 재생합니다.
- **원본 스프라이트가 바라보는 방향**을 **왼쪽/오른쪽**으로 선택하면 즉시 반영됩니다. 반대 방향으로 이동할 때만 좌우 반전합니다.
- **← 왼쪽 / 오른쪽 →** 버튼으로 애니메이션 미리보기 방향을 비교하며, **원본 방향 그대로/좌우 반전 적용됨** 메시지를 확인할 수 있습니다.
- 수직 이동 중과 정지 후에는 마지막 좌우 방향이 유지되고, 새 설정 적용 시 원본 방향에서 시작합니다.
- 캐릭터 픽셀을 흐리지 않도록 nearest-neighbor 렌더링을 적용합니다.
- 입력값 범위를 검증하고 잘못된 프레임 설정 시 안내합니다.

## 프레임별 시간 편집 방법

1. PNG 시트를 업로드하고 IDLE 또는 WALK 탭을 선택합니다.
2. **프레임별 재생 시간 사용**을 켭니다.
3. 각 프레임의 숫자를 변경합니다. 예: 0번 **400ms**, 1번 **100ms**, 2번 **100ms**, 3번 **400ms**.
4. 미리보기에서 프레임별로 머무르는 시간이 달라지는지 확인합니다.
5. **캐릭터에 설정 적용하기**를 눌러 게임에도 적용합니다.
6. FPS 방식이 필요하면 스위치를 끄면 됩니다. 다시 켜면 이전 개별 입력값이 유지됩니다.

**참고:** 100ms = 0.1초, 250ms = 0.25초, 1000ms = 1초입니다. 프레임별 시간 모드에서는 FPS 값이 각 프레임의 초기값·일괄 초기화 기준으로 사용되며, 실제 재생 시간은 프레임별 ms가 결정합니다. 이 설정은 아직 브라우저에 영구 저장되지 않으므로 페이지를 새로고침하면 초기화됩니다.

## GitHub Pages 공개

1. 저장소의 **Settings → Pages**에 들어갑니다.
2. **Build and deployment → Source: Deploy from a branch**를 선택합니다.
3. **Branch: main**, **Folder: /(root)**를 선택하고 **Save**를 누릅니다.
4. 배포가 완료되면 [https://yel2r30.github.io/Dot_it/](https://yel2r30.github.io/Dot_it/)에서 확인할 수 있습니다.

> GitHub Pages 설정은 저장소 관리자가 직접 할 수 있습니다. 초기 로딩에는 Phaser CDN에 연결할 인터넷 환경이 필요합니다.

## 시트 제작 규칙

- PNG, **2MB 이하**, 최대 **2048 × 2048 px**.
- 모든 칸의 크기가 같은 직사각형 격자 시트.
- 예를 들어 32×32 시트의 가로가 192px이고 세로가 64px이면 **6열 × 2행 = 12프레임**입니다.
- 번호는 **0부터 시작**, 왼쪽 → 오른쪽, 위 → 아래 순서입니다.
- 각 애니메이션은 지정한 시작 번호부터 **연속된 프레임**을 사용합니다.
- 투명 PNG가 권장됩니다. 시트 파일은 현재 브라우저에서만 읽고 서버로 업로드하지 않습니다.

## 수동 테스트

1. 페이지를 열어 데모 펭귄이 보이는지 확인합니다.
2. **WASD** 또는 **방향키**를 누르고 걸으면 WALK가 재생되는지 확인합니다.
3. 키에서 손을 떼면 IDLE로 복귀하는지 확인합니다.
4. 새로운 PNG를 업로드해 프레임 크기와 IDLE/WALK 시작 번호·개수·FPS를 지정합니다.
5. 384×240px, 48×48 기준 시트를 업로드하면 전체 8열×5행의 **첫 줄이 잘리지 않고** 보이는지 확인합니다. 스크롤을 위로 올리면 0번 프레임부터 나타나야 합니다.
6. **원본 방향**을 왼쪽으로 선택하고 **← 왼쪽 / 오른쪽 →** 미리보기로 좌우 반전을 확인합니다.
6. IDLE/WALK 탭을 바꾸어 미리보기를 확인하고 **적용하기**를 누릅니다.
7. 원본이 왼쪽인 시트에서 **A/←**로 걸으면 반전되지 않고, **D/→**로 걸으면 반전되는지 확인합니다. 원본 방향이 오른쪽이면 반대로 작동해야 합니다.
8. 위·아래로 움직이거나 멈췄을 때 마지막 좌우 방향이 유지되는지 확인합니다.
9. 프레임 수를 범위 밖으로 설정했을 때 오류 메시지가 출력되는지 확인합니다.
10. 작은 화면에서도 업로드/게임 영역이 정상적으로 보이는지 확인합니다.

## 프레임별 시간 수동 테스트

1. IDLE의 프레임별 시간 모드를 켜고 0번 프레임만 1000ms로, 다른 프레임은 100ms로 설정합니다. 미리보기에 0번이 오래 보이는지 확인합니다.
2. **캐릭터에 설정 적용하기**를 클릭하고 광장에서도 같은 패턴을 보이는지 확인합니다.
3. WALK에 서로 다른 값을 넣고 걷는 중에 적용되는지 확인합니다.
4. IDLE/WALK 탭을 바꿨다가 돌아와도 각자 입력값이 유지되는지 확인합니다.
5. 스위치를 끄면 기존 전체 FPS 방식으로 복원되는지 확인합니다.
6. 20 미만 또는 3000 초과 값을 입력하면 오류 안내가 나타나는지 확인합니다.

## 좌우 반전 확인 방법

1. 기본 데모는 **오른쪽을 바라보는 옆모습 펭귄**이므로 주황색 부리와 연두색 목도리로 반전을 확인할 수 있습니다.
2. **원본 방향: 오른쪽** 상태에서 D를 누르면 원본 그대로, A를 누르면 반전됩니다.
3. 자신이 만든 시트가 **왼쪽을 보는 원본**이라면 원본 방향을 **왼쪽**으로 바꾸면 됩니다. 이제 A에서는 원본 그대로, D에서는 반전됩니다.
4. 방향 선택은 **설정 적용하기를 누르지 않아도 즉시** 광장 캐릭터에 적용됩니다. 게임 밑 **FACING** 상태가 ORIGINAL/FLIPPED로 바뀌는지도 확인합니다.
5. 이전 JS 파일이 브라우저 캐시에 남았다면 Ctrl + F5로 강력 새로고침합니다.

## 좌우 방향 처리 범위

DEV-001은 **하나의 원본 시트를 좌우로 반전해서 표시**하는 방식입니다. 원본의 방향을 고르는 기능이며, 왼쪽·오른쪽에 완전히 다른 그림을 사용하는 **별도 방향 시트** 설정은 아직 지원하지 않습니다.
